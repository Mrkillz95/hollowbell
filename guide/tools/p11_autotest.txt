cmd giants admin script add gatekeeper title The Gatekeeper
cmd giants admin script add gatekeeper say None shall pass!
cmd giants admin script add gatekeeper patrol walls until area gate
cmd giants admin script add gatekeeper say Turn back!
cmd giants admin script add gatekeeper fight 60
cmd giants admin script add gatekeeper guard 32
cmd giants admin script add castaway waitfor players 20
cmd giants admin script add castaway walk walls
cmd giants hook add wreckback half tellraw @a {"text":"The Gatekeeper is badly hurt!","color":"aqua"}
cmd giants hook add all dies say {name} fell at {x} {z}.
cmd giants hook add script.gatekeeper enters.gate playsound minecraft:event.raid.horn hostile @a ~ ~ ~ 3
cmd giants hook scores on
cmd wreckback summon calm 0.12
